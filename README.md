## 🩹 Tabela de Preço Curativo — Clínica Santa Marta

Sistema web de gerenciamento de atendimentos e precificação de curativos desenvolvido para a **Clínica Santa Marta**.

### 📋 Funcionalidades

- **Registro de atendimentos** com nome do paciente, tipo de problema e data
- **Seleção de produtos** com cálculo automático de valores por item e total
- **Múltiplos atendimentos simultâneos** com comparativo de valores lado a lado
- **Seleção individual** para salvar somente os atendimentos desejados
- **Mão de obra** com níveis de cobrança configuráveis
- **Histórico completo** de todos os atendimentos salvos
- **Visualização detalhada** dos produtos de cada atendimento
- **Exportação para Excel** com uma aba por paciente, formatação profissional e logo da clínica como marca d'água
- **Interface responsiva** acessível pelo celular ou computador

### 🛠️ Tecnologias

- HTML5, CSS3 e JavaScript puro
- Biblioteca **xlsx-js-style** para exportação Excel estilizada
- **Firebase Firestore** para histórico compartilhado entre a equipe
- Hospedado via **GitHub Pages**
